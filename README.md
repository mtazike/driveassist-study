# Halden DriveAssist — Study Webpage

Research webpage for a Texas State University study on how drivers understand information about driver-assistance features.

**Status:** Approved by the Texas State University IRB (Protocol #11169, approved 11/05/2026).
**Researchers:** Iman Jamshidi (PI) · Faculty Advisor: Dr. Subasish Das
**Contact:** ijamshidi@txstate.edu

> Halden Motors and DriveAssist are fictional and were created for this study.

## How it is used
- Participants are recruited through Prolific.
- They reach this page only from the first Qualtrics survey, then click **Continue** to go to the second survey.
- Each participant sees one of two versions of the page, assigned randomly by Qualtrics.
- Visiting the page without a study link shows only a short research notice.

## Data recorded
- How participants interact with the page: sections viewed, scrolling, clicks on the Learn More questions, tab switching, and time on page.
- These measures are sent to the second Qualtrics survey with a random study code.
- The page does not collect names, emails, or other personal information.
- GitHub Pages automatically logs visitor IP addresses for security; the research team does not receive this information.
